## 🎨 Design

The webpage uses a **Medium Slate Blue** background with **Sandy Brown** content sections.

The main content uses white text for readability.

The website also uses rounded corners, shadows, animations, and transitions to create a more interactive design.

The content boxes use properties such as:

```css
border-radius: 25px;

The text uses the Franklin Gothic Medium font family.

🖼️ Custom Logo

I created a custom Yaya logo using SVG.

The logo is displayed on the webpage using:

<img src="yaya-logo.svg" alt="The logo I made">

The same logo is also used during the splash screen.

The website also has a custom SVG favicon for the browser tab.

✨ Animations

The website includes several animations.

🚀 Splash Screen

When the website loads, the Yaya logo appears in an animated splash screen before the main website is displayed.

📜 Scroll Reveal

Website sections smoothly appear when they enter the screen while scrolling.

The project uses the JavaScript IntersectionObserver API for this effect.

🖱️ Cursor Glow

On desktop devices, the cursor has a glowing effect that follows the mouse.

💥 Click Effect

Clicking anywhere on the webpage creates an animated glowing ripple.

🌈 Custom Scrollbar

The scrollbar uses a gradient containing blue, yellow, green, and purple.

📱 Responsive Design

The webpage includes a viewport meta tag so it can display correctly on different screen sizes.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

The project also includes responsive CSS for smaller screens.
